📊 How evaluation closes the loop

The 12-needle eval told me the encoders all plateau at ~33% coverage. The metadata-lift experiment told me a single column adds 5× precision. Both findings feed the schema-design decision: which columns to populate at ingest next.

💰 Why this stack is cheap to operate

Mac CPU runs the small encoders locally. Brev L4 GPU bursts only for the VLM passes. Once cached, all queries are sub-second. Pay perception costs once, recover them on every future query.

🦊 Why Foxglove sits at the output edge

Every search result returns a Foxglove deeplink with frame_id + ts_ns. Click → opens the exact MCAP at the right timestamp in the operator's existing tool. Closes the loop from text query to operator review without any new UI to learn.
